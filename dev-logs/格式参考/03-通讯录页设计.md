assets：打包到应用安装包，随应用一起分发的非代码文件，需要在pubspec.yaml里进行声明，语法为：

```yaml
flutter:
  assets:
    - 目录（必须带'/'）或单个文件（不带'/'）路径
```

需要注意：所包含的目录不递归包含子目录，即包含文件夹中的文件，但不包含文件夹中的文件夹。

flutter常规目录结构：

```
   lib/
   ├── main.dart        # 入口
   ├── pages/           # 界面层：一个页面一个文件
   ├── services/        # 服务层：数据读写、外部能力
   ├── models/          # 数据模型（纯数据结构）
   ├── widgets/         # 可复用小部件（多个页面共享的零件）
   └── utils/           # 零散工具函数
```

本次项目统一命名规范，使用不加s的单数形式，确保一致性

ExpansionTile：折叠/展开面板
结构示意：

```
  ┌───────────────────────┐
  │ XXXX             ▼    │  ← tile（整行可点，含箭头）
  ├───────────────────────┤
  │   xxx                 │  ← children（展开才显示）
  │   xxx                 │
  │   xxx                 │
  └───────────────────────┘
```

使用示例：

```dart

  ExpansionTile(
    title: Text(''),
    children: [
      ListTile(title: Text('')),
      ListTile(title: Text('')),
      ListTile(title: Text('')),
      ListTile(title: Text('')),
    ],
  )
```

path_provider：负责查找应用专属数据存放目录的插件，如Android是`Android/data/<包名>/files/`，Windows是`AppData/Roaming/`
需要通过`flutter pub add path_provider `命令添加后再使用

使用示例：

```dart
  import 'package:path_provider/path_provider.dart';

  // 异步方法：返回 Future，用 await 取到目录对象
  final Directory dir = await getApplicationSupportDirectory();

  // 然后用它拼路径
  final worldDir = Directory('${dir.path}/世界');
```

Directory：目录的对象（不是路径字符串）；包含查存在、创建、列出内容等方法
${...}：字符串插值的表达式版——大括号里可以放任意 Dart 表达式，先算出值再拼进字符串，例：

```dart
  var name = '张三';

  // 层级一（你学过的）：$ 后跟一个标识符，直接取变量值
  '你好，$name'           // → '你好，张三'

  // 层级二（新的）：${} 里放表达式——属性访问、方法调用、运算都行
  '长度：${name.length}'  // → '长度：2'
  '大写：${name.toUpperCase()}'  // → '大写：张三'
```

getApplicationSupportDirectory()：返回"当前应用专属目录"对象的 Future Directory，若目录不存在自动创建

Future：一种数据类型，用于异步方法，表示返回未来的值，搭配async使用，示例：

```dart
  Future<void> 导入() async {  // <void>指定数据类型
    ...
  }
```

async：函数标记，使函数体内部能用 await，且函数必须返回 Future类型
await：等待完成，常用于返回Future类型的方法前，使返回值转为Future对应<类型>的值

rootBundle.loadString()，File().writeAsString()：按UTF-8进行读写，适合处理文本类型文件
rootBundle.load()，File().writeAsBytes()：按原始字节进行读写，适合图片、音频等二进制文件

Dart命名规范：

| 对象        | 风格                      | 写法示例                          |
| ----------- | ------------------------- | --------------------------------- |
| 方法 / 变量 | 小驼峰 `lowerCamelCase`   | `importBuiltinWorlds`             |
| 类 / 类型   | 大驼峰 `UpperCamelCase`   | `TabContact`                      |
| 常量        | 小驼峰（**不是**全大写）  | `maxLines`——Dart 不用 `MAX_LINES` |
| 文件 / 包名 | 全小写下划线 `snake_case` | `storage.dart`                    |
| 私有成员    | 小驼峰 + 下划线前缀       | `_expanded`                       |

Directory.create(recursive: true)：自动创建不存在的上级目录
