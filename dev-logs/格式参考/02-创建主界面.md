# 第2节 创建主界面

IndexedStack：在页面切换时对页面的状态（如有下拉进度则保存该下来进度）。在搭建tab页时暂时不需要实现，而在设计聊天页时，需要实现已暂存用户的输入框中的文字等状态信息

起初tab_chat.dart写成这样后，直接在main.dart的主元素中用home:const TabChat()来进行调用，结果在flutter窗口中渲染出了醒目的黑底红字黄下划线的文字界面。原因是没有使用Scaffold，flutter以这种样式进行故意的警告。改用home: const Scaffold(body: TabChat())后渲染正常

```dart
import 'package:flutter/material.dart';

class TabChat extends StatelessWidget {
  const TabChat({super.key});

  @override
  Widget build(BuildContext context) {
    return const Center(child: Text('聊天'));
  }
}
```

Scaffold：一个页面的框架，包含appBar（顶栏）、body（中间内容，不可缺失）、bottomNavigationBar（底部导航栏）、floatingActionButton（悬浮按钮）等结构字段

页面的完整层级：

```
runAPP
└──MaterialApp //有且仅有1个，控制主题、首页和页面的路由
    └── Scaffold //页面骨架
        └── appBar:
        └── body:
```

Widget：页面零件，如Text('文本')，Center()等

build(BuildContext context)：搭建页面的方法，参数暂时不管，视作固定写法

@override：重写标记。父类StatelessWidget内声明了build方法以要求子类必须要有，但父类中的build只作为占位，没有具体的写法，因此用@override声明重写，把占位符填写为自己的内容

const TabChat({super.key});：每个类的固定写法，暂时搁置

StatelessWidget:无记忆，用于显示静态的不变动的数据
StatefulWidget:有记忆，存数据，数据变动后自己刷新:setState()->build->更新
后者要写两个类：

```dart
  class HomePage extends StatefulWidget {
    // 外壳：只负责造出 State
    createState() => _HomePageState();
  }

  class _HomePageState extends State<HomePage> {
    int index = 0;        // 数据存这里
    build() { ... }       // build 也在 State 里
  }
```

为什么分两个？因为 Widget 本身不可变——数据放在可变的 State 里，外壳只负责描述结构。

箭头 => ：单行 return 的简写

```dart
  createState() => _HomePageState();
  // 完全等价于
  createState() {
    return _HomePageState();
  }
```

\_ 开头 = 私有：\_HomePageState 下划线开头 = 只能在本文件用。State 通常没必要给外人用，所以惯例加 \_

State<HomePage>：写死绑定关系，防止错配，同时使State可以用widget.xx访问Homepage的参数

final：运行时确定值
const：编译时确定值

bottomNavigationBar: NavigationBar：框架名:对应使用的零件
bottomNavigationBar：页面底部导航栏
NavigationBar(...)：Material 风格的底部导航栏

icon: Icon(Icons.chat_bubble)：Icon(...) 表示放置一个图标零件， Icons.chat_bubble是Icons这个图标库里的一个具体图标

setState((){...}):StatefulWidget父类中用于界面刷新的方法，{}内执行数据改变的代码，完成后刷新页面，(){...}是一个匿名函数，参数为空

搭建页面跳转逻辑时，用final pages = [TabChat(), TabContact(), TabSetting()];创建页面列表，其顺序和NavigationDestination一一对应
