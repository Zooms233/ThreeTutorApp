### 上课动态热力图 （暂缓实现）

统计行：热力图上方显示「最近半年上课 N 次」（N = 半年内课次总数）。

网格（仿 GitHub contribution graph）：

- 列 = 自然周（本周往回最多 26 周，即半年），行 = 周一至周日共 7 行；**不横向滚动**，列数按可用宽度自适应（桌面完整显示 26 周，窄屏自动减少）
- 每格 12px 圆角小方块（间距 3px），按当天课次数着色（微信绿梯度）：
  - 0 课：`#EBEDF0` 浅灰
  - 1 课：`#9BE9A8`
  - 2 课：`#40C463`
  - 3 课及以上：`#216E39`
- 顶部月份标注：包含某月 1 日的列标注该月英文名（Jan…Dec），文字可延伸至右侧空格
- 星期标注：GitHub 风格左侧只标「Mon / Wed / Fri」三行
- 点按格子：弹出提示「M月D日 · 上课 N 次」

**数据来源**：扫描全部课程的 CHAT 留档 meta.date，按日期聚合计数（一天内多课程多课次叠加）；现扫现算不落盘。

### API 配置

设置页摘要卡（服务商 / 模型 / 当前 Key 遮显+备注名）与右上角齿轮按钮均可进入配置对话框。对话框结构：

- **服务商选择**（下拉，默认 DeepSeek）：
  - **DeepSeek 官方**：接口内置（实测可用 `https://api.deepseek.com`），模型**预填可修改**（预填逻辑：显式 provider=deepseek 时沿用已存值；推断迁移/切回时预填内置默认），只填 API Key
  - **OpenAI 兼容**：自填 Base URL + Model + API Key
- **API Key（当前使用）**：密码框遮显；选用库内 Key 或手填（手填未入库的 Key 保存时自动入库，备注「默认」）
- **Key 库**（CONFIG.keys）：添加（备注+值子对话框，添加即选用）/ 点击选用 / 尾随删除（删使用中的 Key 同步清空当前值）；所有改动在对话框内存态，点「保存」一次性落盘，取消即丢弃

保存校验：接口地址 / 模型 / Key 均非空（isReady）；不满足则提示且不关对话框。

**检验连通性**：对话框左下按钮，用对话框当前态（不落盘）发最小请求（`max_tokens=1`，协议层 `LlmClient.ping`），结果行内展示：成功（绿）含耗时；失败（红）含状态码与可读原因（401=Key 无效 / 404=地址或模型不存在 / 429=限流额度）；检验中按钮禁用。

**数据存储**（CONFIG.json，单 JSON 整写）：

```json
{
  "provider": "deepseek",
  "apiUrl": "https://api.deepseek.com",
  "apiKey": "sk-...",
  "model": "deepseek-v4-flash",
  "keys": [{ "label": "官方", "value": "sk-..." }]
}
```

- provider：deepseek / openai；缺省时设置页按 apiUrl 匹配内置表推断（旧配置迁移无需手动处理）
- apiUrl / apiKey / model：**运行时唯一事实**——选 DeepSeek 时由内置表覆盖，OpenAI 兼容时为用户输入；LLM 调用层不感知服务商概念
- keys：Key 库（label 备注 + value 值）；apiKey 可不在库内（显示为「未入库」，保存时自动入库）
