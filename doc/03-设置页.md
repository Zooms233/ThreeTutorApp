### 上课动态热力图 （暂缓实现）

统计行：热力图上方显示「最近半年上课 N 次」（N = 半年内课次总数）。

网格（仿 GitHub contribution graph）：

- 列 = 自然周（本周往回最多 26 周，即半年），行 = 周一至周日共 7 行；**不横向滚动**，列数按可用宽度自适应（桌面完整显示 26 周，窄屏自动减少）
- 每格 12px 圆角小方块（间距 3px），按当天课次数着色（微信绿梯度）：
  - 0 课：`#EBEDF0` 浅灰
  - 1 课：`#9BE9A8`
  - 2 课：`#40C463`
  - 3 课及以上：`#216E39`
- 顶部月份标注：包含某月 1 日的列标注该月英文名（Jan…Dec），文字可延伸至右侧空格
- 星期标注：GitHub 风格左侧只标「Mon / Wed / Fri」三行
- 点按格子：弹出提示「M月D日 · 上课 N 次」

**数据来源**：扫描全部课程的 CHAT 留档 meta.date，按日期聚合计数（一天内多课程多课次叠加）；现扫现算不落盘。

### API 配置

设置页摘要卡（使用中档的 名称/模型/Key 遮显）与右上角齿轮按钮均可进入配置对话框。核心抽象：**配置档（profile）= 服务商 + 模型 + API Key 三者配套**（不同 Key 对应不同接口与模型，不可拆分单独管理），可存多档、整套切换。

对话框结构（档列表 + 添加/编辑子表单）：

- **档列表**：每档显示 名称 + 服务商 · 模型 · Key 遮显；点击即选用（单选钮标识）；尾随编辑/删除（删选中档回落首档；删光则顶层配置清空，LLM 调用报配置缺失）
- **添加/编辑（共用子表单）**：配置名称（防重名）+ 服务商下拉 + API Key：
  - **DeepSeek 官方**：接口内置（实测可用 `https://api.deepseek.com`），模型**预填可修改**（编辑沿用档内值；添加预填内置默认）
  - **OpenAI 兼容**：自填 Base URL + Model；Base URL 输入时**自动裁剪 `/v1` 之后的路径**（用户常把完整端点粘进来；仅 `/v1` 为独立路径段时认定，`…/v1abc` 与不含 v1 的网关路径不受影响）
- **检验连通性**：主对话框针对选中档；表单子对话框内可对当前填写即时检验（不必先保存）——最小请求（`max_tokens=1`，协议层 `LlmClient.ping`），结果行内展示：成功（绿）含耗时；失败（红）含状态码与可读原因（401=Key 无效 / 404=地址或模型不存在 / 429=限流额度）

保存原子性：档的添加/编辑/删除/选用都在对话框内存态，点「保存」一次性落盘（取消即丢弃）；保存时把选中档同步到顶层运行时字段。

**数据存储**（CONFIG.json，单 JSON 整写）：

```json
{
  "profiles": [
    { "name": "DeepSeek 官方", "provider": "deepseek",
      "apiUrl": "https://api.deepseek.com", "model": "deepseek-v4-flash", "apiKey": "sk-..." },
    { "name": "备用代理", "provider": "openai",
      "apiUrl": "https://api.example.com/v1", "model": "deepseek-chat", "apiKey": "sk-..." }
  ],
  "active": "DeepSeek 官方",
  "apiUrl": "https://api.deepseek.com",
  "model": "deepseek-v4-flash",
  "apiKey": "sk-..."
}
```

- profiles / active：配置档库与使用中档名（档名唯一，编辑改名时同步）
- apiUrl / model / apiKey：**运行时唯一事实** = active 档的同步副本；LLM 调用层（LlmClient）不感知配置档与服务商概念
- 旧配置迁移：无 profiles 时惰性推断（按 apiUrl 匹配内置表）组装为首档，不落盘、首次保存时写入
