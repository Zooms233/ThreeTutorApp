# 03 设置页设计

> 设置页：头像/用户名、API 配置、版本号。

## 设置页

--------------------------------
|             (Z)               |
|            zooms              |
|--------------------------------|
|                                |
| API 配置                      |
|   https://api.openai.com/v1   |
|                                |
| 版本号                        |
|   v1.0.0                      |
|--------------------------------|
| [聊天]    [通讯录]    [**设置**] |
|--------------------------------|

设置页不设 AppBar，顶部居中显示用户头像框和用户名；点击头像或用户名可修改用户名并保存至 CONFIG.json。下方一行「API 配置」：点击弹出配置菜单，包含三项——API URL（如 https://api.openai.com/v1）、API Key、Model（如 gpt-4o / deepseek-chat），保存后用于 LLM 调用，统一支持 OpenAI 兼容协议。再下方一行「版本号」：显示 APP 当前版本号。
