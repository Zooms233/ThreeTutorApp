# 03 设置页设计

> 设置页：API 配置摘要卡（点击进入配置档管理）+ 用量统计入口 + 导师参考提示词 + 版本号；上课动态热力图随用量统计实现（图在统计页，不在设置页）。
> 旧设计（头像/用户名行、列表式 API 配置与版本号行）已废弃。

Banner：左对齐标题「设置」（无右上角按钮）。

主体（ListView，自上而下）：

- **API 摘要卡**：使用中配置档的 名称 + 模型 + Key 遮显；**API 配置唯一入口**（未配置任何档时显示「API 未配置 / 点击设置服务商、模型与 Key」引导文案，同样可点进）；点击进入配置对话框
- **用量统计入口卡**：紧贴摘要卡下方（同组视觉）；点击进入用量统计页（热力图 + 往期课程 token 消耗与缓存命中，详见下节）
- **导师参考提示词卡**：点击弹窗展示 `assets/prompts/tutor_template.md` 全文（SelectableText 可选）+「复制全文」按钮；用途：用户填一句自由创意提示（点名 IP 人物 / 只给氛围背景 / 全交 AI 发挥均可），粘贴到应用外任意 AI，生成单份 .txt（世界名 + 3 位导师的标记文本：指明人物则人格忠于原作，自创则贴合设定，全文 ≤1200 字），再经通讯录设置菜单「导入外部导师文件」导入为自定义世界
- **版本号**：卡片下方隔 32px，居中灰色小字（与 pubspec version 同步，引入 package_info 前硬编码）

### 用量统计

设置页入口卡 → 用量统计页（`usage_page.dart`），展示 token 消耗。页面结构自上而下：**热力图 → 总账卡 → 课程分组**。

#### 消耗热力图（GitHub contribution 风格）

- **数据源**：USAGE.jsonl 账本按日聚合（现读现算）；原设计「扫 CHAT meta 按课次数着色」废弃——账本天然含日期与量，无需扫对话档案
- **着色标准**：颜色深度按**计费加权热度**，非 token 裸量——DeepSeek 官方定价比例（命中 1 / 写入 4 / 输出 16，元每百万 token 归一）作权重，颜色反映费用强度；**悬停/点按仍显示真实 token 数**（不做价格换算展示）：「M月D日 · 消耗 N token」
- **档位**：非零日四分位自适应 4 档（GitHub 标准色 #9BE9A8/#40C463/#30A14E/#216E39，0 = #EBEDF0），抗用量增长；未来日期浅灰不可点
- **窗口**：最多 26 周（半年），列数按可用宽度自适应（4~26 列），起点对齐周一，不横向滚动；顶部月份标注（中文「M月」，仅含当月 1 日的列标注，文字可延伸右侧）；左侧标一/三/五
- **统计行**：图上方「近半年消耗 N token」（窗口内真实 token 总量，k/M 简写）

#### 总账卡与课程分组

- **总账卡**：总输入（拆出命中数）、总输出、缓存命中率；说明小字标注口径（命中约 1/10 计价、仅记成功请求）
- **课程分组**（ExpansionTile，按最近使用降序）：课程名 + 汇总（N 次 · 入/出/命中率）；展开 → 课次小节（留档文件名去后缀，绿字）→ 单次调用行（`M月d日 HH:mm · 场景` + `入 x（命中 y）出 z`）
- **空态**：无记录时提示「暂无用量记录，上过课或问答后这里会出现统计」（热力图同不显示）

### API 配置

设置页摘要卡（**API 配置唯一入口**，使用中档的 名称/模型/Key 遮显）进入配置对话框。核心抽象：**配置档（profile）= 服务商 + 模型 + API Key 三者配套**（不同 Key 对应不同接口与模型，不可拆分单独管理），可存多档、整套切换。

对话框结构（档列表 + 添加/编辑子表单）：

- **档列表**：每档显示 名称 + 服务商 · 模型 · Key 遮显；点击即选用（单选钮标识）；尾随编辑/删除（删选中档回落首档；删光则顶层配置清空，LLM 调用报配置缺失）
- **添加/编辑（共用子表单）**：配置名称（防重名）+ 服务商下拉 + API Key：
  - **DeepSeek 官方**：接口内置（实测可用 `https://api.deepseek.com`），模型**预填可修改**（编辑沿用档内值；添加预填内置默认）
  - **OpenAI 兼容**：自填 Base URL + Model；Base URL 输入时**自动裁剪 `/v1` 之后的路径**（用户常把完整端点粘进来；仅 `/v1` 为独立路径段时认定，`…/v1abc` 与不含 v1 的网关路径不受影响）
- **检验连通性**：主对话框针对选中档；表单子对话框内可对当前填写即时检验（不必先保存）——最小请求（`max_tokens=1`，协议层 `LlmClient.ping`），结果行内展示：成功（绿）含耗时；失败（红）含状态码与可读原因（401=Key 无效 / 404=地址或模型不存在 / 429=限流额度）

保存原子性：档的添加/编辑/删除/选用都在对话框内存态，点「保存」一次性落盘（取消即丢弃）；保存时把选中档同步到顶层运行时字段。

**数据存储**（CONFIG.json，单 JSON 整写）：

```json
{
  "profiles": [
    { "name": "DeepSeek 官方", "provider": "deepseek",
      "apiUrl": "https://api.deepseek.com", "model": "deepseek-v4-flash", "apiKey": "sk-..." },
    { "name": "备用代理", "provider": "openai",
      "apiUrl": "https://api.example.com/v1", "model": "deepseek-chat", "apiKey": "sk-..." }
  ],
  "active": "DeepSeek 官方",
  "apiUrl": "https://api.deepseek.com",
  "model": "deepseek-v4-flash",
  "apiKey": "sk-..."
}
```

- profiles / active：配置档库与使用中档名（档名唯一，编辑改名时同步）
- apiUrl / model / apiKey：**运行时唯一事实** = active 档的同步副本；LLM 调用层（LlmClient）不感知配置档与服务商概念
- 旧配置迁移：无 profiles 时惰性推断（按 apiUrl 匹配内置表）组装为首档，不落盘、首次保存时写入
