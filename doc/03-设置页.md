# 03 设置页设计

> 设置页：上课动态热力图（仿 GitHub contribution graph）+ API 配置。
> 旧设计（头像/用户名行、列表式 API 配置与版本号行）已废弃。

## 设置页

```
--------------------------------
| 设置                     [⚙] |
|--------------------------------|
| 最近一年上课 12 次              |
|                               |
| 一  ┌──────────────           |
|    |□ □ ■ □ □ □ □|           |
| 三  |□ ■ ■ □ □ □ □|  ← 横向滚动|

```

Banner：左对齐标题「设置」；右上角设置图标按钮，点击弹出 API 配置对话框。

### 上课动态热力图 （暂缓实现）

统计行：热力图上方显示「最近半年上课 N 次」（N = 半年内课次总数）。

网格（仿 GitHub contribution graph）：

- 列 = 自然周（本周往回最多 26 周，即半年），行 = 周一至周日共 7 行；**不横向滚动**，列数按可用宽度自适应（桌面完整显示 26 周，窄屏自动减少）
- 每格 12px 圆角小方块（间距 3px），按当天课次数着色（微信绿梯度）：
  - 0 课：`#EBEDF0` 浅灰
  - 1 课：`#9BE9A8`
  - 2 课：`#40C463`
  - 3 课及以上：`#216E39`
- 顶部月份标注：包含某月 1 日的列标注该月英文名（Jan…Dec），文字可延伸至右侧空格
- 星期标注：GitHub 风格左侧只标「Mon / Wed / Fri」三行
- 点按格子：弹出提示「M月D日 · 上课 N 次」

**数据来源**：扫描全部课程的 CHAT 留档 meta.date，按日期聚合计数（一天内多课程多课次叠加）；现扫现算不落盘。

### API 配置

右上角设置图标 → 弹出对话框，包含三项输入：

- API URL（如 `https://api.deepseek.com`）
- API Key（密码框遮显）
- Model（如 `deepseek-v4-flash`）

右下角「保存」按钮：写入 CONFIG.json，用于 LLM 调用，统一支持 OpenAI 兼容协议。

**数据存储**（CONFIG.json，单 JSON 整写）：

```json
{
  "apiUrl": "https://api.deepseek.com",
  "apiKey": "sk-...",
  "model": "deepseek-v4-flash"
}
```

- apiUrl / apiKey / model：API 配置三项（原 username 字段已废弃并移除）

### 版本号

页面底部居中灰色小字，显示 APP 当前版本号。
