# 02 通讯录页设计

> 通讯录世界列表（世界角色展开区）、导师档案页、学习者档案页、导入内置世界。

|                                |
| 教令院智慧宫                    |
|                                |
| 圣芙蕾雅学园                    |
|                                |
|                                |
|                                |
|                                |
|--------------------------------|
| [聊天]    [**通讯录**]  [设置]  |
|--------------------------------|

Banner：左对齐显示软件名 TutorChat；右对齐设置按钮（⚙️），弹出菜单（锚定在按钮右上角）：
- 「导入内置世界」：从 assets/worlds/ 一次性导入 3 个内置世界（教令院、星光咖啡馆、秀知院研究所）到「世界/」目录；逐个检测重名，已存在的世界跳过不导入（不覆盖用户数据）
- 「删除某个世界」：弹出对话框列出当前所有世界供选择，选中后红字二次确认，确认后删除整个世界目录（世界/<世界名>/，连同其中全部角色文件）
- 导入为通用能力：按固定格式导入世界（世界目录 = LEARNER.json + TUTOR/tutor_a.json ~ tutor_c.json）；内置导入即从 assets 按此格式导入，未来可扩展导入任意符合格式的世界文件（需文件选择器）

导师世界列表：每个导师世界一行，仅显示世界名称，无行内按钮；行主体是整个可点区域，点击 = 展开/收起角色区（世界更名功能已删，世界名 = 目录名，不提供改名）。展开区显示四位角色：三位导师与一位学习者，每行一个角色，显示角色名与身份简介（导师：名字 + 身份；学习者：“学习者” + identity（故事角色身份））。点击导师行进入导师档案详情页，点击学习者行进入学习者档案页。

--------------------------------

|   （自然段落）                 |
|                                |

|   （句式特征 + 示例引用）      |
|                                |
| 情绪表现                      |
|   （紧凑要点）                 |
|                                |

|   （自然段落）                 |
|                                |

Banner 左对齐返回按钮，居中显示导师名。返回按钮返回通讯录页。

页面滚动展示该导师完整档案（对应原系统 OWN/<世界名>/TUTOR/TUTOR_X.md）：基本信息（姓名/性别/身份/性格关键词/外观）、性格详写、说话风格与示例、情绪表现、与学习者的关系。

**数据存储**（对应原系统 OWN/<世界名>/TUTOR/TUTOR_X.md，每导师一个 JSON 文件，整写；文件名固定为 tutor_a.json / tutor_b.json / tutor_c.json，导师名读取文件内 name 字段，不依赖文件名）：

```json
{
  "name": "芙宁娜",
  "gender": "女",
  "identity": "荣誉教授",
  "traits": "温柔沉稳、好奇心重",
  "appearance": "……",
  "personality": "性格详写（自然段落）……",
  "speech_style": "句式特征与追问方式概括……",
  "speech_examples": ["示例1（情境）", "示例2（情境）", "……"],
  "emotions": ["情绪表现要点1", "要点2", "……"],
  "relation": "与学习者的关系（自然段落）"
}
```

- name / gender / identity / traits / appearance：基本信息
- personality：性格详写
- speech_style + speech_examples：说话风格与示例（句式概括 + 5~8 条示例引用）
- emotions：情绪表现要点
- relation：与学习者的关系（课后更新时可更新当日授课导师的该字段）

|   你是一个来自异域的旅者……    |
|                                |
|--------------------------------|

Banner 左对齐返回按钮，居中显示用户称呼（世界层称呼未填写时显示「学习者」）。返回按钮返回通讯录页。

页面滚动展示学习者档案（对应原系统 OWN/<世界名>/LEARNER.md）：身份、称呼、学习动力、其他内容、故事背景。

**数据存储**（对应原系统 OWN/<世界名>/LEARNER.md，单 JSON 文件整写）：

```json
{"name":"zooms","motivation":"掌握化学，为考试冲刺","extra":"希望导师多举生活例子","identity":"异域旅者","story":"你是一个来自异域的旅者……"}
```

- name：称呼（创建课程时填写）
- motivation：学习动力（创建课程时填写）
- extra：其他想向导师传达的内容（创建课程时填写，可选）
- identity：故事角色身份（创建导师世界时从 story 提炼；创建课程时随文件继承，不填写）
- story：故事背景（创建导师世界时自动生成）
