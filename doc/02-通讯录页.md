# 02 通讯录页设计

> 通讯录导师列表（按世界分组平铺）、导师资料页、创建课程表单、导师档案页、学习者档案页（预留）、导入内置导师。

## 通讯录页

| -------------------------------- |

|                                  |
|                                  |
|                                  |
|                                  |
|                                  |
| -------------------------------- |
| [聊天] [**通讯录**] [设置]       |

Banner：左对齐显示软件名 三人师；右对齐设置按钮（⚙️），弹出菜单（锚定在按钮右上角）：

- 「导入内置导师」：从 assets/worlds/ 一次性导入内置世界（杏坛）到「世界/」目录；逐个检测重名，已存在的世界跳过不导入（不覆盖用户数据）
- 「导入外部导师」：弹粘贴框（主入口：粘贴 AI 生成的标记文本；次入口：从文件选择 .txt/.md 回填同一输入框）→ `parseTutorTemplate` 解析校验（剥围栏；中英冒号；中英键名白名单兼容；示例句收「- 」行，内联值以“以下/如下”开头跳过防样板说明被抄；字段缺失置空，仅段数≠3 / 某段缺姓名报错）→ 世界名弹窗（预填模板内世界名，必填 + 重名检测在框内）→ 写成新世界（tutor_a/b/c.json），与内置世界同权；模板文本从设置页「导师参考提示词」复制
- 「删除某个世界」：弹出对话框列出当前所有世界供选择，选中后红字二次确认，确认后删除整个世界目录（世界/<世界名>/，连同其中全部角色文件）
- 导入为通用能力：按固定格式导入世界（世界目录 = LEARNER.json + tutor_a.json ~ tutor_c.json，全部平铺无子目录）；内置导入即从 assets 按此格式导入，未来可扩展导入任意符合格式的世界文件（需文件选择器）

导师列表平铺：按世界分组，每个世界一个灰色小字分组标题（显示世界名；世界名 = 目录名，不提供改名），标题下方平铺该世界全部导师，每行一位导师，仅显示导师名，无行内按钮，行主体是整个可点区域，点击进入导师资料页。导师顺序按世界目录下 tutor\_ 开头文件的文件名排序（tutor_a → b → c）。列表不显示学习者条目。

| 子贡                     |
| ……                          |

|--------------------------------|
```

```

Banner 左对齐返回按钮（返回通讯录页）；头部居中显示导师名与身份；下方白色行按钮列表：

- 「导师资料」：进入导师档案详情页
- 「创建群聊」：始终显示（一个世界可建多个群聊），点击打开创建课程表单
- 「进入群聊」：按课程数量分流——无课程时提示先创建；仅一个课程直接进入；多个课程弹出底部菜单选择课程后进入（聊天页会话列表可直达群聊，此处不重复罗列课程行）

课程匹配：扫描「课程/」目录，比对课程内导师 JSON 的 name 字段与当前导师名。

### 创建课程表单

```
--------------------------------
| ‹  创建群聊                    |
|--------------------------------|
| 课程名：                       |
| 称呼：                         |
| 学习动力：                     |
| 其他想向导师传达的内容：        |
| 教材路径（可选）  [选择文件]    |
|                               |
|                    [完成]     |
|--------------------------------|
```

Banner 左对齐返回按钮（返回导师资料页），居中显示「创建群聊」。表单字段：

- 课程名：必填，即群聊名
- 称呼：用户希望被导师称作的称呼
- 学习动力：
- 其他想向导师传达的内容（可选）
- 教材路径（可选）：系统文件选择器选取，选取后复制进课程 TEXTBOOK/ 目录；不选则进入无教材模式
- 右下角「完成」：创建课程目录（<存储路径>/课程/<课程名>/，从当前导师所在世界复制 LEARNER.json 与 tutor\_\*.json），完成后进入该课程群聊页
- 导师世界不提供选择：世界由发起创建的导师决定

| ‹ 颜回                         |
| -------------------------------- |
|                                  |
| 基本信息                         |

| 性格关键词：温柔沉稳             |
|                                  |
| 性格与动机                       |
| （压缩段落）                     |
|                                  |
| 说话风格与示例                   |
| （句式特征 + 示例引用）          |
|                                  |
| 与学习者的关系                   |
| （自然段落）                     |
|                                  |
| -------------------------------- |

Banner 左对齐返回按钮，居中显示导师名。返回按钮返回通讯录页。

页面滚动展示该导师完整档案（对应原系统 OWN/<世界名>/TUTOR/TUTOR_X.md）：基本信息（姓名/性别/身份/性格关键词）、性格与动机（压缩版）、说话风格与示例、与学习者的关系。

**数据存储**（对应原系统 OWN/<世界名>/TUTOR/TUTOR_X.md，每导师一个 JSON 文件，整写；文件名固定为 tutor_a.json / tutor_b.json / tutor_c.json，导师名读取文件内 name 字段，不依赖文件名）：

```json
{
  "name": "颜回",
  "identity": "荣誉教授",
  "traits": "温柔沉稳、好奇心重",
  "personality": "性格与动机（压缩版）：核心动机一句 + 与其他导师的关系钩子 + 可复用梗，≤150 字",
  "speech_style": "句式特征与追问方式概括……",
  "speech_examples": [
    "示例1（情境）",
    "示例2（情境）",
    "示例3（情境）",
    "示例4（情境）"
  ],
  "relation": "与学习者的关系（自然段落）"
}
```

- name / identity / traits：基本信息
- personality：性格与动机，压缩版（≤150 字）——行为输出由 traits/speech_style 决定，详写背景故事对教学对话边际贡献趋零；保留导师间互动钩子供群聊使用，不写外貌（纯视觉描写对文本对话无贡献）
- speech_style + speech_examples：说话风格与示例（句式概括 + 4 条精选示例，覆盖引导/检验/鼓励/风格签名）
- relation：与学习者的关系（课后更新时可更新当日授课导师的该字段）
