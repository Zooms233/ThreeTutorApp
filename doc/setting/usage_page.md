### 消耗热力图（GitHub contribution 风格）

```
        近半年消耗 45.6k token         ← 窗口内真实 token 总量（k/M 简写）
            2月        3月        4月
  一   ░  ░  ░  ░  ░  ░  ░  ░  ░  ░
  三   ░  ░  ▓  ░  ░  ░  █  ░  ░  ░    ← 点按格子：M月D日 · 消耗 N token
  五   ░  ░  ░  ░  ░  ▒  ░  ░  ░  ░       （真实 token 数，不做价格换算）

  色阶（浅色主题；深色主题为 GitHub Dark 另套）：
  ░ #EBEDF0 空    ▒ #9BE9A8    ▓ #40C463
  █ #30A14E       ■ #216E39 最深
```

- 数据源：USAGE.jsonl 按日聚合；着色按计费加权热度（命中 1 / 写入 4 / 输出 16，反映费用强度而非 token 裸量），非零日按四分位自适应 4 档，抗用量增长
- 窗口最多 26 周（半年），列数按宽度自适应 4~26 列，起点对齐周一，不横向滚动；左侧标一/三/五；未来日期浅灰不可点

### 孤儿清理（AppBar 右上 ⚙️）

deleteCourse 只删课程目录，USAGE.jsonl 的行会残留（孤儿行，页面仍按课程分组展示）。点击后扫描 → 确认 → 重写账本：

```
无残留：SnackBar「没有已删除课程的残留记录」

有残留：
┌────────────────────────────────────────────────┐
│  清理用量残留                                  │
│                                                │
│  检测到 2 门已删除课程的用量记录（共 34 条）：    │
│  细胞生物学、有机化学                            │  ← ≤5 门全列，超出折叠「…等 N 门」
│                                                │
│  删除后不可恢复，确定清理吗？                     │
│                                                │
│               [取消]      [清理]                │  ← 红底警示
└────────────────────────────────────────────────┘
```

- 确认后剔除孤儿行（course 为空的行保留），toast「已清理 N 门课程的 M 条记录」并刷新

数据存储（USAGE.jsonl，与 CONFIG.json 同级，逐行 JSON 追加写）

```json
{"time":"2026-08-04T20:31:05","course":"遗传学","lesson":"第3课.jsonl","scene":"上课","input":3320,"output":1502,"cacheRead":1792,"reasoning":0}
```

- `scene` 七场景：上课 / 问候 / 问答 / 闲聊 / 更新 / 群聊 / 提炼；`lesson` = 课次留档文件名（无课次上下文为 null）
- `input` = 缓存未命中输入（计费且写入缓存）、`cacheRead` = 命中（约 1/10 计价）、`output` = completion_tokens（含思考）、`reasoning` = 思考 token
- 账本只记成功请求（失败重试的中间请求拿不到 usage）；ping 检验不计；写账失败静默（fire-and-forget）；坏行跳过（允许手工编辑）；每次进入页面现读现算
