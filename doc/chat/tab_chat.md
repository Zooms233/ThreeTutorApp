# 聊天页（tab_chat）

### 主页面

```
╔════════════════════════════════════════════════╗
║  三人师                                    ⚙   ║  ← ⚙ 菜单（见下）
║                                                ║
║  ┌──────────────────────────────────────────┐  ║
║  │  [化]  化学入门                           │  ║  ← 群头像 = 课程名首字渐变占位
║  │        导师：先别急着定义——电子…           │  ║     预览单行截断；生成中改显绿色
║  │                             08-04         │  ║     busy 文案（跨页面共享）
║  ├──────────────────────────────────────────┤  ║     时间位 = 最新课次 meta.date 的 MM-DD
║  │  [高]  高等数学                       ➊   │  ║
║  │        尚未开始上课                       │  ║  ← 无 CHAT 文件：预览垫底、时间留空
║  └──────────────────────────────────────────┘  ║
║                                                ║
╠════════════════════════════════════════════════╣
║   💬(选)      👥          ⚙️                   ║  ➋
╚════════════════════════════════════════════════╝
```

- ➊ 会话行 → [群聊页](group_chat_page.md)；从群聊页返回即刷新列表（预览/排序跟随最新落档）
- ➋ 底部 Tab → [通讯录页](../contact/tab_contact.md) / [设置页](../setting/tab_setting.md)

### ⚙ 菜单（AppBar 右侧弹出）

```
        ┌──────────────────────────┐
        │ 更名群聊                  │  ← 群名 = 课程名 = 课程目录名
        │ 删除群聊                  │
        └──────────────────────────┘
```

```
更名群聊：
┌ 选择要更名的群聊 ────┐   ┌ 更名课程 ──────────┐
│  化学入门            │ → │ [化学入门]          │  ← 预填旧名；失败 SnackBar
│  高等数学            │   └────────────────────┘     （非法字符 / 同名已存在）
└─────────────────────┘

删除群聊：
┌ 选择要删除的群聊 ────┐   ┌ 删除「化学入门」？ ───────────────────┐
│  ……                 │ → │ 将删除该群聊的全部对话与学习进度，      │
└─────────────────────┘   │ 删除后不可恢复。确定删除？             │
                          │           [取消]    [删除](红字)       │
                          └──────────────────────────────────────┘
→ 删除整个课程目录（对话 + 进度 + 档案副本）
```

- 选择对话框列出全部群聊（限高滚动）；无群聊时提示「当前没有群聊」

### 会话行数据

- 每行一个课程群聊，现扫「课程/」目录组装；排序按最后活动倒序（最后一条消息 time；无消息用 meta.date 兑底；无日期垫底）
- 预览 = 最新 CHAT 文件最后一条 message，跨文件从后往前找（讨论写在上一课文件尾，最新消息可能在倒数第二个文件）；他人消息带「发言者: 」前缀，自己消息不带；Markdown/LaTeX 剥标记显示（公式显示【公式】）
- 生成中：预览位绿色 busy 文案（如「颜回 正在输入中…」）；刷新时机 = 从群聊页返回、切回聊天 tab、busy 变更
