### 上课控制按钮（AppBar 右上）

| 状态 | 显示 | 点击 |
|---|---|---|
| 课程生成中（busy） | 「正在处理中…」灰色禁用 | —（下课流程全程锁定，避免并发操作状态机） |
| 最新课次 ongoing（上课中） | 「今天就到这里」 | 课后更新 → 群聊生成（meta 改写 ended、下一课文件创建） |
| 其余（idle / ended） | 「开始上课」 | 开新课次建档（meta 预填 idle、tutor = STATE.next_tutor）→ 课前问候 |

- 执行发生在群聊页（本页只回传意图）：问候失败 meta 保持 ongoing，可直接发消息继续上课；课后更新失败 meta 保持 ongoing、大纲不勾选，重新点击重跑
- 点击后自动返回群聊页看生成过程；完成后按钮自动恢复（meta 已改写）

### 教学进度入口行（副标题派生自大纲 checkbox）

- 有大纲：`{当前节标题} · {已学 n/m}`（当前节 = 第一个含待学行的节）
- 无大纲：「未设置大纲」；全 [x]：「已学完全部内容」

### 知识点进度（主体）

- 平铺列表，按首次出现倒序（新知识点在前）；每行默认两行：`{状态} {短名}` + `最近 {date} → 复习 {review}`
- 状态 ✓ 掌握 / △ 薄弱 / ✗ 未掌握；△/✗ 时第二行下方红字错因【】（≤15 字）
- 点击知识点行展开全部历史状态块（最新块之下从新到旧，含当时错因），再点收起
- 空进度提示「暂无学习进度，完成第一节课后自动生成」

数据存储（STATE.json 单行 JSON，课后更新时整行重写）

```json
{"next_tutor":"颜回","lessons":5,"last_date":"2026-08-04"}
```

- `next_tutor`：下一节课授课导师（每课后按 tutor_a→b→c 轮换推进）
- `lessons`：累计课时（每课后 +1）；`last_date`：最近上课日期
- 历史遗留 `position` 字段见 [创建课程表单](../contact/create_course_page.md)

数据存储（PROGRESS.jsonl，每行一个知识点；文件行序旧→新，展示时新在前）

```jsonl
{"name":"氧化还原反应","records":[{"status":"✓","date":"2026-03-15","review":"2026-03-22"}]}
{"name":"化学平衡移动","records":[{"status":"△","date":"2026-03-18","review":"2026-03-21","mistake":"混淆常数与速率"},{"status":"✓","date":"2026-03-25","review":"2026-04-01"}]}
```

- `name`：知识点短名（2-8 字）；`records`：状态块数组，按时间顺序只追加不修改
- `review`：app 端按 records 序列自适应——首次登记 ✓+7；连续 ✓ 递增 7→14→30→60 封顶；△+3 / ✗+1 重置
- `mistake`：错因（≤15 字），仅 △/✗ 时存在
- 上课注入的知识点清单中，到期（review ≤ 今日）知识点打 ★待复习（≤3 条，按 ✗ > △ > 到期早的 ✓ 优先）——调度归 app、表达归导师（见[教学过程](../教学过程.md)）
