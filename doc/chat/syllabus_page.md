### 只读与焦点说明

- v1 只读：勾选由课后结算自动维护——手动勾选会绕过结算一致性（勾了 [x] 但 PROGRESS 无对应记录），不做
- 第一个待学行高亮「（进行中）」仅作**参考焦点**——乱序学习时以对话实际为准
- 纠正状态是逃生门：外部直接编辑大纲文件，本页重进即重读（勾选只替换 checkbox 记号，其余字节由结算保证）
- 大纲三条结构约定（两级标题 / 二态 / 文本全文唯一）见[教学过程](../教学过程.md)

数据存储（课程 OUTLINE/<课程名>-outline.txt，仅一份；大纲即进度文件）

```markdown
# 第五章 连锁遗传和性连锁

## 连锁基因的交换和重组型配子

- [x] 完全连锁与不完全连锁
- [x] 交换与重组

## 交换值测定、基因定位与连锁图

- [ ] 重组率
```

- 导入与更换入口在 [课程资料页](relation_page.md)（粘贴为主 / 选文件为次，选定即校验）
- 勾选唯一写点：课后结算（逐字照抄 + 证据 + 双闸门校验，见[教学过程](../教学过程.md)）
