### 学习者编辑对话框（✎）

```
┌ 编辑学习者档案 ───────────────────────┐
│  称呼      [zooms]                    │  ← 必填（空提示「称呼与学习动力不能为空」）
│  学习动力  [掌握化学，为考试冲刺]       │  ← 必填
│  其他      [希望导师多举生活例子]       │  ← 选填，留空存空串
│                     ✨ 从最近课次提炼  │  ← 置灰：课次文件不足 2
│                [取消]    [保存]        │     提炼中转圈；结果整段替换「其他」
└──────────────────────────────────────┘
```

- 保存只覆盖 name / motivation / extra 三键；prompt 每次请求现读 LEARNER.json，保存后下一句话即生效
- 「从最近课次提炼」：读本课程最近 3 份课次留档全文（跳过最新 1 篇——多为下课流程刚创建的空下一课文件），`learner_extra.md` 作 system；提示文案与消耗（scene=提炼）同 [创建课程表单](../contact/create_course_page.md)
- 导师关系段不在此列（由课后更新演进，不可编辑）

### 导师组切换（⇄）

```
┌ 选择导师组世界 ────────┐   ┌ 切换到世界「新杏坛」？ ─────────────┐
│  杏坛                  │ → │ 导师对学习者的评价将从头开始，       │
│  新杏坛                │   │ 当前评价不会保留。                  │
│  （列出全部世界）       │   │           [取消]    [切换]          │
└───────────────────────┘   └────────────────────────────────────┘
→ 新组 tutor_a~c.json 覆盖课程内副本
```

- 轮换衔接：旧 next_tutor 按名字定位字母位（a/b/c，找不到回退 a）→ 新组同位导师名写 STATE.next_tutor 与最新课次 meta.tutor——tutor_a→b→c 节奏不变仅换人
- 切换后下一条课间问答即由新组同位导师回复；无课次文件（建课未交流）只写 STATE，第 1 课懒建时自动带上
- 选原世界 = 用世界档案初始版覆盖副本，即评价重置（行为对所有世界统一）；不备份，历史消息中旧导师名照常保留
- 置灰 / 兜底复检：上课中（含下课流程滞留 ongoing）或生成中不可切换（toast 提示）；无世界提示先在[通讯录页](../contact/tab_contact.md)导入

### 教学大纲 / 教学材料

- 大纲：粘贴导入（主入口，与导师组导入同款对话框）/ 选文件（次入口）；导入即校验，不合格 SnackBar 展示行号错误且**旧大纲原样保留**；固定文件名 <课程名>-outline.txt（校验规则见 [创建课程表单](../contact/create_course_page.md)）
- 材料：选文件复制进 TEXTBOOK/（选择器不可用不影响主流程提示）；删除二次确认「删除「X」？/ 删除后 AI 将无法再查阅该文件。」
- 增删后系统现读现拼（prompt 每次请求现读文件），下一句对话即生效

数据存储（读取课程目录：课程/<课程名>/）

- `LEARNER.json`：name / motivation / extra
- `OUTLINE/`：大纲全文（含 checkbox 状态，即进度文件）
- `TEXTBOOK/`：多份参考材料（.md/.markdown/.txt/.text/.log 才纳入目录与 read 工具）
- `tutor_a.json ~ tutor_c.json`：课程内副本的 name 与 relation（创建课程/切换导师组时从世界复制，非世界目录静态版本）
