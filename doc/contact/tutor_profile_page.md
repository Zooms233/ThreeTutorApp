# 导师档案详情页（tutor_profile_page）

### 主页面（滚动展示，进入时懒加载世界档案）

```
╔════════════════════════════════════════════════╗
║  ‹  颜回                                       ║  ← 顶栏标题 = 导师名（档案 name 字段）
║                                                ║
║  基本信息                                       ║
║  身份：荣誉教授                                 ║
║  性格关键词：温柔沉稳                            ║  ← 姓名/性别不展示（性别字段已废）
║                                                ║
║  性格与动机                                     ║
║  核心动机一句 + 与其他导师的关系钩子 +            ║
║  可复用梗（压缩版，≤150 字）                     ║
║                                                ║
║  说话风格与示例                                 ║
║  句式特征与追问方式概括……                        ║
║  · 示例1（情境）                                ║  ← speech_examples 列表
║  · 示例2（情境）                                ║
║  · 示例3（情境）                                ║
║  · 示例4（情境）                                ║
║                                                ║
║  与学习者的关系                                 ║
║  （自然段落——世界档案初始版本；                  ║
║    课程内由课后更新演进，见课程资料页）           ║
╚════════════════════════════════════════════════╝
```

- 返回 → 上一页（导师资料页，经由 [通讯录页](tab_contact.md) 进入；无其他页面跳转）
- 页面只读：教学行为由 traits / speech_style 驱动（注入教学请求）；本页仅为人工查阅

数据存储（世界/<世界名>/tutor_x.json，静态版本；课程建课/切换导师组时复制副本到课程目录）

```json
{
  "name": "颜回",
  "identity": "荣誉教授",
  "traits": "温柔沉稳、好奇心重",
  "personality": "性格与动机（压缩版，≤150 字）",
  "speech_style": "句式特征与追问方式概括……",
  "speech_examples": ["示例1（情境）", "示例2（情境）", "示例3（情境）", "示例4（情境）"],
  "relation": "与学习者的关系（世界档案初始版）"
}
```

- 导师名读取文件内 name 字段，不依赖文件名
- 课程内副本的 relation 由课后更新演进，展示与编辑见 [课程资料页](../chat/relation_page.md)
