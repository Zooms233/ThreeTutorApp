### 导入外部导师（粘贴对话框 → 世界名弹窗）

```
┌ 导入外部导师 ─────────────────────────┐
│  ┌────────────────────────────────┐  │
│  │ 粘贴按「导师参考提示词」生成的   │  │  ← 主入口=粘贴全文
│  │ 全文……                         │  │     次入口=「从文件选择」txt/md 回填
│  └────────────────────────────────┘  │
│                     📄 从文件选择     │
│                 [取消]    [导入]      │
└──────────────────────────────────────┘
        ↓ 解析校验（失败 SnackBar 3s）
┌ 导师组命名 ───────────────────────────┐
│  世界名                               │
│  ┌────────────────────────────────┐  │
│  │ 杏坛新世界                      │  │  ← 预填模板内世界名
│  └────────────────────────────────┘  │     必填 + 重名检测在框内报错
│                 [取消]    [确定]      │
└──────────────────────────────────────┘
        ↓ 写成新世界（tutor_a/b/c.json），与内置世界同权
```

解析宽容规则（`parseTutorTemplate`）：

- 键名白名单中英兼容：姓名/name、身份/identity、性格关键词/traits、性格与动机/personality、说话风格/speech_style、示例句/speech_examples、关系/relation
- 剥代码围栏；中英冒号；示例句收「- 」行，内联值以「以下/如下」开头跳过（防样板说明被照抄）；非键行并入上一字段；字段缺失置空串
- 仅两类错报错：导师段数≠3 / 某段缺姓名（分段行需含「导师」二字）

### 删除某个世界

```
┌ 选择要删除的世界 ─────────────────────┐
│  杏坛                                 │  ← 列出当前所有世界
│  ……                                  │
└──────────────────────────────────────┘
        ↓
┌ 删除「杏坛」？ ───────────────────────┐
│  删除后不可恢复，确定删除？             │
│           [取消]    [删除]             │  ← 红字警示
└──────────────────────────────────────┘
```

- 确认后删除整个世界目录（世界/<世界名>/，连同其中全部角色文件）；无世界可删时提示「当前没有世界可删除」

数据存储（世界/<世界名>/，平铺 tutor_a.json ~ tutor_c.json，无子目录；学习者档案不内置——创建课程时由表单字段生成 LEARNER.json）

```json
{
  "name": "颜回",
  "identity": "荣誉教授",
  "traits": "温柔沉稳、好奇心重",
  "personality": "性格与动机（压缩版，≤150 字）",
  "speech_style": "句式特征与追问方式概括……",
  "speech_examples": ["示例1（情境）", "示例2（情境）", "示例3（情境）", "示例4（情境）"],
  "relation": "与学习者的关系（世界档案初始版）"
}
```

- 模板文本从设置页「导师参考提示词」复制（见 [../setting/tab_setting.md](../setting/tab_setting.md)）
