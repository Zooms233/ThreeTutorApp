### 「从最近课程提炼」（其他字段的 LLM 辅助）

跨课程收素材 → 提炼通用画像 → 整段预填「其他」输入框（只预填不落盘，用户看过/改过随建课写入）：

- 素材：每门课程忽略最新 1 篇（多为下课流程刚创建的空下一课文件），余下按文件创建时间取最新 3 份课次留档全文，新→旧，每份带「课程 · 课次」头
- 提炼规则 `assets/prompts/learner_extra.md` 作 system，来自另一门课程时追加「提炼可跨课程迁移的通用画像」提示
- 置灰：全应用无可用素材，或提炼中
- 提示文案：素材不足「暂无课次记录」；无可提炼特征「最近课次中没有值得记录的学习者特征」（提示而非填入「无」）；失败「提炼失败：$e」；消耗入 USAGE.jsonl（scene=提炼，见 [../setting/usage_page.md](../setting/usage_page.md)）

### 教学大纲导入（粘贴为主 / 选文件为次）

两条路径统一持文本，选定即校验（大纲即进度文件，格式规范见设置页「大纲提示词」）；不通过则不记录选择，弹窗逐条展示行号错误：

```
┌ 大纲格式校验未通过 ───────────────────┐
│  第 3 行：知识点行必须出现在节标题之后  │
│  第 7 行：节「X」内没有知识点行         │
│              [知道了]                  │
└──────────────────────────────────────┘
```

### 提交流程（「完成」按钮）

```
1. 大纲再校验（不合格拒绝建课，失败时无半成品目录残留）
2. 建 课程/<课程名>/ 目录 + CHAT/
3. tutor_a~c.json 从当前导师所在世界复制快照
4. LEARNER.json 由表单字段直接生成
5. STATE.json 初值（next_tutor=tutor_a 名、lessons=0、last_date 空）
6. 教材复制进 TEXTBOOK/（选了才有）、大纲写入 OUTLINE/<课程名>-outline.txt（选了才有）
```

- 失败：SnackBar 3s 留在表单（同名课程已存在 / 大纲校验未通过 / 创建失败：$e）
- 第 1 课 CHAT 文件不在此时创建——首条消息发送或「开始上课」时懒建（见 [../chat/tab_chat.md](../chat/tab_chat.md)）

数据存储（建课产物：课程/<课程名>/）

```json
LEARNER.json
{
  "name": "zooms",
  "motivation": "掌握化学，为考试冲刺",
  "extra": "希望导师多举生活例子"
}
```

- STATE.json：`{"position":"","next_tutor":"颜回","lessons":0,"last_date":""}`（position 为历史遗留字段，已无消费方）
- 后续建后管理（编辑学习者/换大纲/删材料/换导师组）→ [课程资料页](../chat/relation_page.md)
