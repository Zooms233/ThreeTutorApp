# 01 聊天页设计

> 会话列表（课程群聊）+ 群聊页（上课与课后闲聊同一消息流）+ 课程信息页、课程进度页、关系页。

## 界面视图

```
[聊天页=会话列表] ⇄ [通讯录页] ⇄ [设置页]      底部 Tab 互切，默认「聊天」
   │
   └ 点击会话行 → [群聊页]
   │               └ 右上 [统计图标] → [课程详情页]（状态四项 + 知识点进度）
   │                                 └ [和导师的关系] → [关系页]（返回课程详情页）
   └ 长按会话行 → 更名 / 删除课程（删除红字二次确认）
```

[通讯录页] → 点击导师行 → [导师资料页]
                              ├ [导师资料] → [导师档案详情页]（返回导师资料页）
                              ├ [创建群聊] → [创建课程表单] → 完成后进入 [群聊页]
                              └ 点击课程行 → [群聊页]

[设置页]：底部 Tab 直达

## 聊天页（会话列表）

```
--------------------------------
| TutorChat                    |
|--------------------------------|
| 化学入门                       |
|   导师：先别急着定义——电子…    |
|   2026-08-04                  |
|                               |
| 高等数学                       |
|   尚未开始上课                 |
|                               |
|--------------------------------|
| [**聊天**]  [通讯录]  [设置]   |
|--------------------------------|
```

Banner：左对齐软件名 TutorChat；无右上按钮（创建课程入口统一在通讯录导师资料页）。

会话列表：每行一个课程群聊，微信会话样式：群名 + 最后一条消息预览（单行截断）+ 最近时间。按最近活动倒序（最近有新消息的在前）。点击行进入群聊页；长按行弹出菜单：更名（弹重命名对话框，群名 = 课程名 = 课程目录名）/ 删除课程（红字二次确认，删除整个课程目录）。

会话数据：扫描「课程/」目录下全部课程；每课程读取最新 CHAT 文件——meta 行提供课次与日期，文件最后一条 message 做预览；课程无 CHAT 文件时预览显示「尚未开始上课」，时间位留空。

空状态：居中图标 + 文案「前往通讯录，选择导师创建群聊」。

## 群聊页（课程对话与课后闲聊同一页）

```
--------------------------------
| ‹  化学入门               ⋮  |
|--------------------------------|
| --- 第 2 课 · 芙宁娜 · 08-04 --- |
|                        zooms  |
|              氧化还原反应的实质 |
| 芙宁娜                        |
|   先别急着定义——电子转移前后…  |
| --- 下课后 ---                 |
| 纳西妲                        |
|   话说他今天那个追问挺厉害的    |
|                               |
|--------------------------------|
| 输入框                    发送 |
|--------------------------------|
```

Banner：左对齐返回按钮（返回聊天页）；居中显示群名（= 课程名）；右对齐统计图标按钮（Icons.query_stats），点击进入课程详情页。

消息流：全部课次连续显示（含课后闲聊），行序即时间序。

- 课次分隔行：`第 N 课 · 导师名 · MM-DD`（由各 CHAT 文件 meta 行渲染；仅 UI 装饰，不写入文件）
- 课后分隔行：`下课后`（渲染于当天第一条 phase=social 消息之前；仅 UI 装饰）
- 从未上课：消息流顶部显示 `你加入了群聊，现在可以开始聊天了`（仅 UI 装饰；此后不存在空白消息页）
- 分隔行统一为两侧细线 + 居中灰色小字样式（示意图中的 --- 仅为文案示意）
- 消息条目：微信群聊样式——导师消息左对齐（发言者名 + 内容），用户消息右对齐（显示称呼）；支持 Markdown 与 LaTeX（`$...$` 行内、`$$...$$` 独立行）

输入框状态机（进入页面时检测最新 CHAT 文件 meta 的 status）：

- 无 CHAT 文件或最新课 ended：输入框可用；输入「开始上课」触发课前准备——读 STATE 确定当日授课导师、创建当日 CHAT 文件并写入 meta、当日导师以人设打招呼并宣布今天的学习内容
- 最新课 ongoing（上课中）：正常收发；输入「今天就到这」触发下课总结
- 下课总结完成后自动执行课后更新：输入框与发送按钮禁用
- 课后更新完成（meta 改写为 ended）：输入框恢复可用——用户可继续在群里闲聊，导师以人设回应（消息以 phase=social 追加）

LLM 生成期间：Banner 群名替换为「<导师名> 正在输入中…」（上课时为当日授课导师，课后闲聊为实际发言导师），生成完成恢复群名。

每条消息实时写入当日 CHAT 文件（JSONL 逐条追加，先写后说）。

输入交互：桌面端 Ctrl+Enter 发送、Enter 换行（输入框 1~6 行自适应，超过内部滚动）；移动端软键盘 Enter 即换行，靠发送按钮发送。

## 课程详情页（群聊页右上统计图标进入）

```
--------------------------------
| ‹  课程详情                    |
|--------------------------------|
| 当前讲授位置  3-2 化学平衡移动  |
| 下一节课授课导师  芙宁娜        |
| 累计课时  5                    |
| 最近上课日期  2026-08-04       |
|                               |
| [和导师的关系]              ›  |
|--------------------------------|
| ✓ 氧化还原反应                 |
|    最近 03-15 → 复习 03-22     |
| △ 化学平衡移动                 |
|    最近 03-18 → 复习 03-21     |
|    【混淆常数与速率】           |
| ✗ 电化学计算                   |
|--------------------------------|
```

Banner 左对齐返回按钮（返回群聊页），居中显示「课程详情」。

- 顶部状态四项：当前讲授位置、下一节课授课导师（每课后按 tutor_a→b→c 轮换推进）、累计课时、最近上课日期；每次进入读取 STATE
- 「和导师的关系」入口 → 关系页
- 主体为知识点进度（见下）
- 更名与删除课程在聊天页会话长按菜单（不再放详情页）

**数据存储**（对应原系统 DATA/STATE.md，单行 JSON，课后更新时整行重写）：

```json
{"position":"3-2 化学平衡移动","next_tutor":"芙宁娜","lessons":5,"last_date":"2026-08-04"}
```

- position：当前讲授位置（无教材模式保持为空）
- next_tutor：下一节课授课导师（每课后按 tutor_a→b→c 轮换推进）
- lessons：累计课时（每课后 +1）
- last_date：最近上课日期（每课后更新）

#### 知识点进度（课程详情页主体）

平铺知识点进度列表，按首次出现倒序排列（新知识点在前）。每个知识点占两行：第一行显示状态标记（✓ 掌握 / △ 薄弱 / ✗ 未掌握）和知识点短名；第二行显示最近一次接触日期、下次复习日期（→日期）。状态为 △/✗ 时在第二行下方额外显示错因（【】内，≤15 字）。


**数据存储**（对应原系统 DATA/PROGRESS.md，JSONL 格式，每行一个知识点）：

```jsonl
{"name":"氧化还原反应","records":[{"status":"✓","date":"2026-03-15","review":"2026-03-22"}]}
{"name":"化学平衡移动","records":[{"status":"△","date":"2026-03-18","review":"2026-03-21","mistake":"混淆常数与速率"},{"status":"✓","date":"2026-03-25","review":"2026-04-01"}]}
```

- name：知识点短名（2-8 字），行序即首次出现顺序；页面展示时新知识点在前
- records：状态块数组，按时间顺序只追加不修改
- status：✓ 掌握 / △ 薄弱 / ✗ 未掌握
- date：本次接触日期
- review：下次复习日期（✓+7d / △+3d / ✗+1d）
- mistake：错因（≤15 字），仅 △/✗ 时存在

课后更新规则：新知识点 → 追加一行；已有知识点 → 整行重写，records 追加新状态块。（review 字段仅记录下次复习日期，系统不触发任何提醒）

## 数据存储

课程目录：<存储路径>/课程/<课程名>/，内含 STATE.json、PROGRESS.jsonl、LEARNER.json、tutor_a.json ~ tutor_c.json、TEXTBOOK/（可选教材）、CHAT/。

CHAT/YYYY-MM-DD-第N课.jsonl（N = 累计课时 + 1，自动计算；上课对话与课后闲聊同文件）：

```jsonl
{"type":"meta","lesson":2,"date":"2026-08-04","tutor":"芙宁娜","status":"ongoing"}
{"type":"message","phase":"teaching","role":"user","name":"zooms","content":"氧化还原反应的实质是什么？"}
{"type":"message","phase":"teaching","role":"tutor","name":"芙宁娜","content":"先别急着定义——电子转移前后，什么发生了变化？"}
{"type":"message","phase":"social","role":"tutor","name":"纳西妲","content":"话说他今天那个追问挺厉害的"}
{"type":"message","phase":"social","role":"user","name":"zooms","content":"我也觉得那道题好难"}
```

- type：meta（首行元数据）/ message（消息）
- meta：lesson 课次、date 日期、tutor 本课授课导师、status（ongoing 上课中 / ended 已完成课后更新；课后更新完成时整行改写）
- message.phase：teaching 上课对话 / social 课后闲聊（渲染「下课后」分隔行的依据）
- role：user / tutor；name：发言者名（用户为称呼，导师为导师名）；content：消息内容（支持 Markdown 与 LaTeX）
- 行序即时间顺序，不存储时间戳；课后闲聊的节奏（首条=下课+0~10 分钟、间隔 10~40 秒、同人连发 3~8 秒、总跨度≤10 分钟）由生成端控制
- 原 SOCIAL/ 目录取消：课后导师闲聊与用户参与直接追加进当日 CHAT 文件

直写规则：每轮导师生成回复后、显示前，一次追加用户消息与导师回复两行（先写后说）。

## 取消的页面与入口

- 课程对话页、群聊对话页、历史消息页：统一并入群聊页（连续消息流上滑即历史）
- 课程信息页与课程进度页：并入课程详情页（状态四项 + 知识点进度 + 关系入口）
- 群聊页 ⋮ 菜单：右上角改为统计图标直达课程详情页；更名/删除课程移至聊天页会话长按菜单
- 聊天页「+」创建课程菜单：创建入口统一到通讯录导师资料页
- 课后更新完成后的「打开群聊」按钮：不再需要（本就在群里，输入框恢复可用即代表可闲聊）
